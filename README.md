# Мини-приложение «Уровни» — бот подсказок RFX, версия 1.8

Статическая страница для Telegram: правка уровней сетки пальцем до «Беру» и (позже) стопа и цели
открытой позиции. Сервера нет — только файлы этой папки. Договор — `bot_next18\SPEC_18.md`
(разделы 1–4, 10, 11).

## Как это работает

1. Бот присылает кнопку **нижней клавиатуры** чата: «Уровни №214 SOL» (сетка до «Беру») или
   «Стоп/цель №209 NEAR» (открытая позиция). Адрес кнопки несёт параметры: № кандидата, монета,
   сторона, шаги цены и объёма, риск, уровни бота (`b`) и стартовые уровни (`o`).
2. Страница сама берёт свечи M5 с публичного API Bybit (запасной — Binance) и обновляет их каждые
   15 секунд, пока открыта.
3. Линии L1, L2, L3, стоп и цель двигаются пальцем на графике или кнопками: ▼ ▲ — на один шаг цены
   (удержание повторяет), ⤓ ⤒ — к соседнему уровню M5 (вершины и впадины последних 8 часов и уровни
   бота), «Вернуть уровни бота».
4. Объём, риск и R:R считаются **тем же правилом, что у бота** (`rules.js` — точная копия правил
   Python, счёт дробями без округлений с плавающей точкой). Ошибки порядка уровней — красным,
   «Готово» тогда неактивна.
5. «Готово» отправляет боту короткий JSON (до 4096 байт) **через сам Telegram**
   (`Telegram.WebApp.sendData`): он приходит служебным сообщением в ваш чат с ботом. Бот принимает
   его только из вашего чата и от вас, всё проверяет заново и присылает подтверждение с кнопками
   «Беру с моими уровнями» / «Ещё изменить» / «Отмена». Сама страница ничего не ставит на бирже.
6. «Отмена» просто закрывает страницу, ничего не отправляя.

## Секретов нет

- В файлах и в адресе страницы нет ключей, токенов, номера чата, имён. Страница публичная — её
  код можно открыть и прочитать.
- Сеть (закреплено политикой `Content-Security-Policy` в `index.html`): `api.bybit.com` и
  `fapi.binance.com` — только чтение свечей; `telegram.org` — официальный скрипт Telegram. Больше
  страница никуда не обращается.
- Нет счётчиков, аналитики, куки и хранилища браузера. Биржам не передаётся адрес страницы
  (`no-referrer`).
- Торговых вызовов нет: заявки ставит бот на демо-счёте после вашего подтверждения в чате.

## Файлы

| файл | что это |
|---|---|
| `index.html`, `app.js`, `style.css` | страница: график, линии, кнопки, расчёт, Telegram |
| `rules.js` | правила расчёта (объём, риск, порядок уровней, позиция, уровни M5, адрес, данные для бота) |
| `selftest.html`, `selftest.js` | самопроверка правил |
| `selftest/fixtures.js` | примеры, созданные кодом бота (`bot_next18\tools\make_miniapp_fixtures.py`), не править руками |
| `vendor/` | библиотека графика TradingView Lightweight Charts 5.2.1 (Apache 2.0): `LICENSE`, `NOTICE`, `VERSIONS.txt` |
| `.nojekyll` | GitHub Pages отдаёт файлы как есть |

## Самопроверка

Откройте `selftest.html` (на компьютере или после публикации — в Safari на iPhone). В заголовке
вкладки должно быть «SELFTEST OK N/N» (сейчас 3587 примеров: объём и риск, порядок уровней,
позиция, уровни M5, разбор адреса, данные для бота). Примеры пересоздаются командой
`python -B -X utf8 bot_next18\tools\make_miniapp_fixtures.py`; она же сверяет их с правилами бота
(`miniapp_rules.py`).

Проверка на компьютере без публикации: `python -I -B -m http.server 8765 --bind 127.0.0.1
--directory <путь к этой папке>`, затем `http://127.0.0.1:8765/selftest.html` и
`http://127.0.0.1:8765/index.html?…` (адрес — как у кнопки бота). Вне Telegram «Готово» выключена.

## Библиотека графика

TradingView Lightweight Charts™ 5.2.1, © TradingView, Inc., лицензия Apache 2.0. Берётся из
пакета npm без изменений (`bot_next18\tools\fetch_miniapp_vendor.py --apply` — сверяет integrity
архива и записывает sha256 в `vendor/VERSIONS.txt`). Знак TradingView на графике и строка внизу
страницы — требование лицензии. Пока библиотеки нет, страница работает без графика: линии
двигаются кнопками, расчёт и отправка работают.

## Публикация (только после отдельного «да» владельца)

Нужен постоянный адрес `https`; сервер, домен и регистрация в BotFather не нужны.

1. `gh repo create bagginsdmitry-beep/rfx-levels --public` (бесплатные GitHub Pages — только у
   открытого репозитория; секретов здесь нет).
2. В репозиторий — содержимое этой папки без `CHANGES_18_PAGE.md`; коммит.
3. Pages: ветка `main`, корень.
4. Через 1–10 минут `https://bagginsdmitry-beep.github.io/rfx-levels/selftest.html` → «SELFTEST OK».
5. В боте: `[miniapp] enabled = true`, перезапуск (поправка с датой).
6. На iPhone: `/уровни` → кнопка внизу → сдвинуть линию → «Готово» → пришло подтверждение.

Обновление страницы — новый коммит; версия `PAGE_VERSION` в `rules.js` меняется вместе с ботом
(при расхождении страница просит закрыть и открыть её заново).
